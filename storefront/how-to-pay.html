How to pay with x402

Plain-English walkthrough of HTTP 402 → USDC authorization on Base → facilitator verify/settle → receipt. Same money on MCP via _meta payment fields.

Payments are live. This is the exact flow the gateway at api.defifintechdirectory.com runs today.
  1. You (or your agent) request a tool — HTTP POST /tools/{id} or MCP tools/call.
  2. The server answers Payment Required (HTTP 402) with price, Base network, USDC, and the receive wallet (payTo).
  3. Your wallet signs a USDC authorization (EIP-3009). You typically don’t pay gas for that step — the facilitator does.
  4. You retry with the signed proof (PAYMENT-SIGNATURE header, or MCP _meta["x402/payment"]).
  5. The server verifies, runs the tool, settles on Base, and returns the result plus a payment receipt.
  6. No account, no Stripe, no API key for buyers.

Network details

  • Network: eip155:8453 (Base mainnet)
  • Asset: USDC · Scheme: exact
  • payTo: 0x96873Fb532C630aE88c5e8A5dF5ef430c92dfF32
  • HTTP base: https://api.defifintechdirectory.com
