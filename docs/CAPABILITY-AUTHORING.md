# Capability authoring

Run `npm run capability:new -- --id example_utility --category utility --price 0.002`. Optional `--input-schema` and `--output-schema` take JSON strings. The command is noninteractive and creates `generated/capabilities/example_utility/{handler.ts,manifest.ts,capability.test.js,README.md}`. It refuses an existing directory. The default handler deliberately throws `not_implemented`; generated smoke tests only verify that disabled state, not product completion.

Use `npm run capability:validate` to validate built-in and generated manifests. Run `node --test generated/capabilities/example_utility/capability.test.js` for scaffold tests. `npm run discovery:build` writes an ignored local artifact and never contacts a registry. All generated capabilities start disabled, noncommercial and undiscoverable.

For a future authorized product: replace the handler with a bounded implementation; make JSON Schemas describe every accepted input and output; add happy-path, malformed-input, timeout, output-schema, cost and transport contract tests. Register the manifest once in `createRegistry`; HTTP, MCP and catalog adapters consume it. Preserve IDs and version contracts. Ajv strict schema compilation fails startup on unsupported schema vocabulary. Do not accept arbitrary remote schema references.

Prices are USDC atomic integers; decimal conversion is exact up to six places. Cost limits are conservative estimates and need measured upstream validation. Use a real per-call maximum and daily ceiling; zero cost is only appropriate for a genuinely local computation. Handler cancellation is cooperative; do not ignore the provided AbortSignal or launch detached work. Non-abortable external side effects need separate idempotent provider contracts and reconciliation.

For URL reads, use `safeGet` with a reviewed exact hostname allowlist, caller AbortSignal and byte cap. It accepts HTTPS/443, pins a resolved public IPv4 address, rejects credentials, private/special addresses, mixed unsafe DNS answers, and redirects. IPv6 is conservatively denied pending complete range support. Apply response content-type/file-type checks appropriate to the future capability. Never add a public arbitrary shell, repository execution or paid API passthrough without its own threat review.

Current provider policy accepts `av-hub` only. Discovery flags cannot make placeholders commercial. Three local implementations remain unlisted and noncommercial; commercial launch, marketplace providers, deployment and live paid calls require separate review. Research decisions must link to provenance and distinguish observations from estimated demand and cost.
